                              Adoption Cycle Errata

        The purpose of this bulletin is to notify code users of error and format corrections being
        made to the 2025    California Building Standards Code (California Code of Regulations,
        Title 24). A summary of noteworthy  topics specific to these  errata is discussed below.
        Additionally, this bulletin explains the purpose and application of errata.

        These changes are   published as errata (buff  -colored     pages) to various parts of the
        standards, and become effective and enforceable   January 1, 2026, to coincide       with the
        effective date of the 2025     California Building Standards Code.     Errata have been issued
        for the following Title    24 Parts:
             •     Part 2 -          California Building Code, Volumes 1 and 2
             •     Part 2.5 -      California Residential Code
             •     Part 3 -          California Electrical Code
             •     Part 4 -          California Mechanical Code
             •     Part 5 -          California Plumbing Code
             •     Part 6 -          California Energy Code
             •     Part 9 -          California Fire Code
             •     Part 10 -       California Existing Building Code
             •     Part 11 -       California Green Building Standards Code (CALGreen)

        Background
        The 2025 edition of the California Building Standards Code was published on or before
        July 1, 2025,   and is now available.   Since publication, efforts have been made to ensure
        that all items that underwent rulemaking   in the code adoption cycle are corr     ectly
        represented in the 2025    publication, and that regulations carried forward   are accurately
        placed. Additionally, grammatical and spelling errors, erroneous references, and other
        minor misprints that have been identified by users and publishing staff are corrected
        with this Errata, both for model code  language     and for California amendments. Errata
        can be issued at any time because there is no commission a   ction necessary to
        promulgate those changes. The objective is to ease interpretation issues and enhance
        understandability in the use of the codes.

===== Page 2 =====
        Errata
        When corrections are necessary to resolve   an error such as spelling or numerical
        mistakes that do not establish   new code requirements, errata are issued on buff-colored
        paper. Errata may also include items that were erroneously omitted from printing but
        were completed   during a previous rulemaking cycle. Errata, like supplements , are
        published by the respective code publishers (see page 10)     with instructions concerning
        the code pages to be removed and replaced, and contain a History Note Appendix
        listing the effective date.   More information about the application of the errata,
        maintaining Title 24, and obtaining issued errata copies is provided   in the 2025 Guide to
        Title 24 and Maintaining Your Title 24 guide.

        Enforcement Responsibility
        The requirements within the California Building Standards Code establish the minimum
        regulations for the design and construction of buildings and structures in California.
        State law, in various cases, mandates that local government enforce these regulations
        and any local ordinances with qualified reasonably necessary and generally more
        restrictive building standards than provided for in the California Building Standards
        Code.
        Exceptions for enforcement are for building standards applicable to hospitals, state
        buildings, public schools and colleges that are subject to state agency authority. For
        detailed information regarding enforcement responsibilities refer to Part 1 of Title 24 and
        Chapter 1 of most Parts of Title 24.

        Amendment by Local Ordinance
        Local ordinances amending the California Building Standards Code are subject to
        requirements of California law. Ordinances generally must be more restrictive than the
        building standards approved/adopted by the California Building Standards Commission
        (CBSC). These amendments must be filed, as appropriate, with either CBSC or other
        state agencies as directed by law. CBSC developed a Guide for Local Amendments of
        Building Standards, which is available on its website for download or printing by
        navigating to the Resources webpage. Additionally, CBSC        developed in cooperation
        with the International Code Council, the California Code Adoption for Local Jurisdictions
        video, available on YouTube.
        CBSC also issued Information Bulletin 25    -02     (August 2025) relative to local government
        amendments adopted via ordinance, that addresses filing with and acceptance by
        CBSC or other agencies prior to enforcement.

        Effective Date and Application of the 2025        California Building Standards Code
        January 1, 2026,   is the statewide effective date established by CBSC for the 2025
        California Building Standards Code. All applications for a building permit that occur on
        or after January 1, 2026 , are subject to compliance with the 2025      edition of the
        California Building Standards Code.
        The 2022 California Building Standards Code is applicable to all submitted permit
        applications, where such application for a building permit was  received on or before
        December 31, 2025 .
