                                                  Adoption of the 2024 Code



On July 16, 2025, The City of Las Vegas, City Council approved the ordinances to adopt the following national codes
and local amendments:

         2024 International Building Code
         2024 International Residential Code
         2024 International Existing Building Code
         2024 International Swimming Pool and Spa Code
         2023 National Electrical Code
         2024 Uniform Plumbing Code
         2024 Uniform Mechanical Code
         2024 International Energy Conservation Code
         2024 International Fire Code
         2024 International Wildland Urban Interface Code

To allow the industry time to accommodate this adoption, the effective date of the codes will be January 5, 2026.
Projects submitted between now and January 5, 2026 may submit under the current codes or the 2024 codes.
Any project with an initial submittal on or after January 5, 2026 shall be submitted and designed to the 2024 codes.






Michael Cunningham, P.E., C.B.O.,
