Houston Code Archive

Body

The Houston Construction Code establishes minimum standards for the construction, alteration, maintenance, repair, and demolition of buildings and other structures to protect the life safety of the public. The Houston amendments, along with the model codes, constitute the City of Houston Construction Code. 

The Houston Construction Code is adopted and amended by City Council. The latest revision was approved by City Council on October 25, 2023, and became effective on January 1, 2024. The currently adopted 2021 Houston Construction Code can be found here: 2021 Code Amendments

For information on the 2021 Construction Code adoption process, please visit the Construction Code Modernization page.
